# 1.整数：
十进制数字直接写，十六进制就在前面加0x就可以了
如果数字过大，则可以用`_`来间隔，例如：`1000000`可以写成`1_000_000`，二者的效果是完全一样的，十六进制也是如此
# 2.浮点数：
正常的小数还是正常表示，如果要用科学计数法来表示，就用`e`来替代`10`.如`1.23 \times 10^{9}`就可以写成`1.23e9`
# 3.字符串与转义字符
""与''只是一种表示方式，不属于字符串，当'属于一个字符是就要用""括起来，如"I'm OK!"
如果字符串中既出现'又出现"，就要使用转义字符\
如：想输出I'm "OK"!
则字符串应该为：
```python
'I\'m \"OK\"!'
```
## 3.1其他转义字符：
>1.`\n`:表示换行
>2.`\t`表示制表符
>3.`\`自身也可以转义，则用`\\`来表示直接输出`\`
输出时设置如果为`r''`则里面的内容不用转义，如：
```python
print(r'\\\t\\')
'\\\t\\'
```
如果当'\n'影响正常阅读时，可以用'''...'''来表示多行内容，如：
```python
print('''line1
...line2
...line3''')
```
输出：
```
line1
line2
line3
```
# 4.布尔值:
##布尔值只分为True和False
```python
3>2 #为True
3>5 #为False
```
## 4.1布尔值可以用`and`,`or`和`not`来进行运算
用`and`的情况，只有全为True才是True，有一个False则为False
用`or`的情况,只要一个为True，则就为Ture
用`not`的情况，就是把True变成False，把False变成Ture，如：
```python
>>>not True
False
>>>not False
True
```
# 5.空值
空值用`None`表示，空值≠0，空值是无意义的
# 6.变量
命名方式同c相同，变量名是数字，字母，符号的组合，不能用数字来开头和关键词来当变量名
其运用的规则也和c比较类似
```python
>>>a_1 = 1
#变量a_1是一个整数
>>>b_2 = 'cuit'
#变量b_2是一个字符串
>>>c_3 = True
#变量c_3是一个布尔值
```
用`=`来对变量可以进行反复新的赋值，而且可以是不同类型的变量
```python
a = 123 #对a赋值的是整数类型
a = 'cuit' #对a新赋值的是字符串类型
```
因为Python是动态语言类型，与之对应的是静态语言类型，像之前学过的c和java，如果已经提前对变量限定了赋值类型，赋值以外的类型，就会报错，如：
```python
int a = 123 #此时对a变量赋值的是整数类型
a = 'cuit' #后面想对a赋值非与整数类型的类型赋值，就会出现报错
```
相对于静态语言相比，动态语言对于变量赋值则更为灵活
同时，不要把`=`当作数学符号来看待
```python
x = 2
x = x + 2
```
在数学中二式是不成立的，但是本段中先对x赋值为整数2，在将x=2代入进二式中，在把新的值赋值给x
在本段中x最终赋值为的是4
## 6.1.变量在计算机内存中的表示：
```python
a = 'ABC' #a变量现在赋值的是一个字符串，a指向的是那一串字符串
b = a #引入新变量b，把b指向a所现在指向的字符串，相当于就是变量a和b都指向先前的那一串字符串
a = 'XYZ' #现在a指向另一串新的字符串，b还是指向新的那一串字符串
print(b)
```
所以输出结果自然就是`ABC`
# 7.常量
在Python中通常用全部大写来表示常量
像PI这种：
```python
PI = 3.14159265359
```
但事实上PI仍然是一个变量，可以去任意修改的，单独的Python是没有任何额外的机制去保证这个常量不会被修改的，除非去引入额外的库numpy这种
```python
import numpy as np
print(np.pi)  # 输出: 3.141592653589793
```
## 7.1Python中的两种除法
>1.第一种除法是`/`：
>>`/`除出来的是浮点数，哪怕是整除，结果也是浮点数
```python
a = 10 / 3
print(a) #输出的结果为3.3333333333333335
b = 9 / 3
print(b) #输出的结果为3.0
```
具体为什么不是3.3333333...，具体的原因是因为十进制里的 1/3，在二进制里是无限循环小数，计算机只能存一个“近似值”。这个近似值，转回十进制时，四舍五入后就是 3.3333333333333335。
>2.第二种除法是`//`
>>两个不整除的数除出来还是整数
```python
a = 10 // 3
print(a) #输出结果为3
```
`//`永远是整数，即使是除不尽的情况下
>>同时Python还提供一个取余的运算，和c是一样的
```python
a = 10 % 3
print(a) #输出的结果为1
```
